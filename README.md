# 🤖 FinBot - Assistente Financeiro Pessoal

> Seu assistente financeiro inteligente feito em Python

## 🚀 O que é?

FinBot é um sistema de controle financeiro pessoal com:
- Registro de gastos e receitas
- Dashboard com gráficos
- Categorização inteligente
- Interface moderna e intuitiva

## 🛠️ Tecnologias

- **Python 3.10+**
- **Streamlit** (interface)
- **Pandas** (dados)
- **Plotly** (gráficos)

## 📦 Instalação

```bash
# Clone o projeto
git clone https://github.com/SEU_USER/finbot.git
cd finbot

# Crie o ambiente virtual
python -m venv venv

# Ative o ambiente
venv\Scripts\activate  # Windows
source venv/bin/activate  # Mac/Linux

# Instale as dependências
pip install -r requirements.txt

# Execute
streamlit run app.py
